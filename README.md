# Multi-Format Scientific & Engineering Calculator

## Project Overview
A Python-based calculator designed to perform basic arithmetic, scientific calculations, statistical operations, and unit conversions.

## Features
- Basic arithmetic operations
- Scientific functions such as square root, logarithm, trigonometry, and factorial
- Statistical calculations including mean, median, and standard deviation
- Unit conversions for length, mass, and temperature
- Input validation and error handling

## Technologies Used
- Python 3
- `math` module
- `statistics` module

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python scientific_calculator.py
```
